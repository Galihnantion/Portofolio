================================================================================
                            QUICK START COMMANDS
================================================================================

1. Install dependencies:
   cd d:\Laravel\Portfolio
   composer install

2. Setup environment:
   copy .env.example .env
   php artisan key:generate

3. Configure database in .env:
   DB_DATABASE=portfolio_laravel
   DB_USERNAME=root
   DB_PASSWORD=

4. Setup database:
   php artisan migrate
   php artisan db:seed --class=PortfolioSeeder
   php artisan storage:link

5. Run development server:
   php artisan serve

6. Open in browser:
   http://localhost:8000

================================================================================
                         TROUBLESHOOTING GUIDE
================================================================================

Error: Halaman tidak muncul
   → php artisan cache:clear
   → php artisan config:cache

Error: Gambar tidak ditampilkan
   → php artisan storage:link
   → Check storage/app/public/portfolio/ folder

Error: Database connection failed
   → Edit .env file - check DB_DATABASE, DB_USERNAME, DB_PASSWORD
   → Create database manually if not exists
   → Run: php artisan migrate

Error: Port 8000 already in use
   → php artisan serve --port=8001
   → Or kill process on port 8000

Error: Permission denied on storage
   → chmod -R 775 storage (Linux/Mac)
   → Check folder permissions (Windows)
