┌─ QUICK START (60 SECONDS) ─────────────────────────────────────────────────┐
│                                                                             │
│  1. Open Terminal/Command Prompt                                           │
│                                                                             │
│  2. Copy & Paste Ini:                                                      │
│     cd d:\Laravel\Portfolio && composer install                            │
│                                                                             │
│  3. Edit .env file:                                                        │
│     - DB_DATABASE=portfolio_laravel                                        │
│     - DB_USERNAME=root                                                     │
│     - DB_PASSWORD= (kosong jika default)                                   │
│                                                                             │
│  4. Run Commands:                                                          │
│     php artisan key:generate                                               │
│     php artisan migrate                                                    │
│     php artisan db:seed --class=PortfolioSeeder                            │
│     php artisan storage:link                                               │
│     php artisan serve                                                      │
│                                                                             │
│  5. Buka Browser:                                                          │
│     http://localhost:8000                                                  │
│                                                                             │
│  Done! ✅ Portfolio Anda siap!                                             │
│                                                                             │

   php artisan storage:link

   ──────────

🆘 PROBLEM QUICK FIX:

   ❌ Halaman Error?
   ✅ php artisan cache:clear

   ❌ Gambar Tidak Muncul?
   ✅ php artisan storage:link

   ❌ Database Connection Error?
   ✅ Edit .env dengan DB credentials yang benar

   ❌ Port 8000 Sudah Digunakan?
   ✅ php artisan serve --port=8001
