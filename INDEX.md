## 💻 QUICK COMMANDS

### Setup (Copy & Paste)

```bash
cd d:\Laravel\Portfolio
composer install
copy .env.example .env
php artisan key:generate
php artisan migrate
php artisan db:seed --class=PortfolioSeeder
php artisan storage:link
php artisan serve
```

### Then Open

```
http://localhost:8000
```
